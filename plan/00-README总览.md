| 2026-10-16 | **M3 修正 M1 合成数据的"重试期望不可推导"缺陷** | 旧数据所有调用间隔 3 秒 → "窗口内失败后再调用"对每个 server 都成立（实测 24/10/1/8/10/18），而 truth 声明"仅重试型 server 有 8 次" → **期望值不可由日志复算**（真值沦为植入断言）。**改为重试型 server 用窗口内节奏（3s）、其余用窗口外节奏（200s）**，并把 `expected_retry_count` 改为**由实际序列 + 窗口规则复算**（与引擎 SQL 实现相互独立）。守门 + 变异项 24 |
| 2026-10-16 | **口径唯一性白名单扩为三处（含真值生成器）** | `plan/03 §2.3` 原文只列 `aggregate.py` / `attribute.py` / `tests/`。实现时发现生成器必须推导**期望值**，而它与引擎**必须独立**（共用 = 真值沦为引擎自证，K12 明禁）。白名单逐条论证：`aggregate.py` / `attribute.py` / `tools/gen_synthetic_logs.py`（`tests/` 不进扫描面）。见 `tests/test_aggregate.py::DIV_ALLOWED_FILES` |
| 2026-10-16 | **口径唯一性白名单扩为四处（M4 新增基准 `bench.py`）** | 基准算的是**解析质量指标**（precision / recall / F1），是"一致性比率"而非域口径（`failure_rate` / `turn_token_avg`）的第二份计算；域口径仍只在 `aggregate.py` / `attribute.py` / 生成器三处。落点只有 `_ratio()` 一处。**扩充而非放宽**，见 `DIV_ALLOWED_FILES` 逐条论证 |
| 2026-10-16 | **M4 每套件探活 = "重跑 check 且必须报差异"** | 探活不能只是"再跑一遍对账"，那对恒真的守门无反应。定为：注入缺陷 → **用同一套 check 重跑** → 必须报出 ≥1 条差异；未变红 = 假门，基准自判未达标（exit 1）。本棒据此抓出自己 3 个真假门（断言只读派生载荷） |
| 2026-10-16 | **基准的观测一律运行时实算（K12 落地形态）** | `bench.build_bundle()` 重新扫描 + 聚合 + 归因得到引擎输出，与 `truth.json` 无数据通路；测试用"篡改真值期望值不影响引擎实算输出"证伪"偷读真值当观测" |
| 2026-10-16 | **计数级 F1 的口径如实标注为聚合粒度** | 真值是**程序化精确植入**的 server 级计数（非逐条标注）→ 解析基线按逐 server 错误计数建混淆矩阵；F1 = 1 等价于逐 server 错误计数完全一致，**不等于**逐条分类质量。该口径写进 `metrics.definition` 与 README，不夸大 |
| 2026-10-16 | **`hashlib` 进 stdlib 冻结名单** | 基准需要 sha256 表达"双跑逐字节一致"（与既有跨进程复核同源）；同步登记进 `tests/test_discipline.py::STDLIB_FROZEN` |
| 2026-10-16 | **M5 报告层落为独立包 `report/`（不放进 `pipeline.py`）** | 分层铁律要求"报告层零判定、不 import 引擎层"。独立包使 **AST 守门可按目录扫描**（`report/` 内无 `BinOp(Div)`、无引擎 import），比"扫描单文件"更难绕。落点：`report/{__init__,markdown,html,guard,suggestions}.py` |
